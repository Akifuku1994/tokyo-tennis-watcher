# 都立公園テニスコート空き通知

都立公園スポーツレクリエーション予約システムの公開空き状況を確認し、新しく空きが出たときだけメールを送ります。ログインや予約操作は行いません。

## 設定済みの条件

- 対象：日比谷公園、芝公園、猿江恩賜公園、亀戸中央公園、木場公園、有明テニスＡ屋外ハードコート
- 対象日：土曜・日曜・祝日（予約サイトの休日表示を使用）
- 除外：当日から3日以内
- 時間帯：終日
- 起動：cron-job.orgから7:00〜23:50 JST、10分おき
- 監視範囲：1回の起動で6公園すべてを確認
- 一時障害：1公園を確認できなくても、ほかの公園の監視を継続
- アクセス制限：検知後6時間はサイトへ接続せず、自動的に再開

## GitHubで動かす手順

リポジトリの `Settings` → `Secrets and variables` → `Actions` に次のSecretsを登録します。

| Secret | 内容（Gmailの場合） |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | 送信に使うGmailアドレス |
| `SMTP_PASS` | Googleのアプリパスワード（通常のログインパスワードは禁止） |
| `MAIL_TO` | 通知を受け取るメールアドレス |
| `MAIL_FROM` | 省略可。通常は`SMTP_USER`と同じ |

`Actions`タブで`tennis-availability-watch`を開き、`Run workflow`で手動実行できます。

## 動作上の注意

- 空き通知は予約を保証しません。メール到着後、公式画面から予約してください。
- 外部サイトの一時的な通信障害はGitHub Actionsの警告として残し、取得済みの状態を消さずに次回へ継続します。
- 画面構造の変更などコード修正が必要な異常は、見逃さないようGitHub Actionsを失敗させます。
- 監視間隔をこれ以上短くしたり、同時実行数を増やしたりしないでください。
