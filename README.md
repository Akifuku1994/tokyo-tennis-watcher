# 都立公園テニスコート空き通知

都立公園スポーツレクリエーション予約システムの公開空き状況を確認し、新しく空きが出たときだけメールを送ります。ログインや予約操作は行いません。

## 設定済みの条件

- 対象：日比谷公園、芝公園、猿江恩賜公園、亀戸中央公園、木場公園、有明テニスＡ屋外ハードコート
- 対象日：土曜・日曜・祝日（予約サイトの休日表示を使用）
- 除外：当日から3日以内。今日が8月14日なら8月17日まで無視し、8月18日以降を対象にします
- 時間帯：終日
- 起動：7:00〜22:40 JST、20分おき＋0〜3分のランダム待機
- 監視範囲：1回の起動で6公園すべてを確認
- 負荷対策：月間表示で空きのある対象日だけ時間帯を追加確認
- 制限検知：6時間停止。エラー時の連続再試行なし

## GitHubで動かす手順

1. GitHubで非公開リポジトリを作ります。
2. このフォルダの中身をリポジトリへアップロードします。
3. リポジトリの `Settings` → `Secrets and variables` → `Actions` で次のSecretsを登録します。

| Secret | 内容（Gmailの場合） |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | 送信に使うGmailアドレス |
| `SMTP_PASS` | Googleのアプリパスワード（通常のログインパスワードは禁止） |
| `MAIL_TO` | 通知を受け取るメールアドレス |
| `MAIL_FROM` | 省略可。通常は`SMTP_USER`と同じ |

4. `Actions` タブで `tennis-availability-watch` を開き、`Run workflow` で手動実行します。
5. 成功後はスケジュール実行されます。GitHubの仕様上、開始が数分遅れることがあります。

## Gmailの準備

Googleアカウントで2段階認証を有効にし、アプリパスワードを発行して `SMTP_PASS` に登録します。通常のGoogleパスワードは登録しないでください。

## 注意

- 空き通知は予約を保証しません。メール到着後、本人が公式画面から予約してください。
- 公式サイトは過剰アクセスを制限することがあります。監視間隔を短くしたり、同時実行数を増やしたりしないでください。
- GitHubのクラウド環境から公式サイトへの接続が制限される可能性があります。その場合は、自宅PCで同じプログラムを定期実行する方式へ切り替えてください。
- 予約サイトの画面変更時は、監視コードの調整が必要になる場合があります。
